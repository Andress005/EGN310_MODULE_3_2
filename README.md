# EGN310 Module 3.1 — LinkedList

## Overview

This project implements a singly linked list in Python from scratch.

The linked list is made up of nodes. Each node stores a data value and a reference to the next node in the list.

The project includes automated tests using pytest to verify that the linked list operations work correctly.
